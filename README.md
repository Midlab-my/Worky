### 📈 O Projeto: Worky

O **Worky** é uma solução acadêmica focada na extração de tendências do LinkedIn e outras plataformas de vagas:
- **Análise Semântica:** Diferencia habilidades técnicas reais de termos genéricos usando NLP.
- **Tendências de Mercado:** Dashboards dinâmicos com média salarial e tecnologias em alta.
- **Wireframe Funcional:** Interface minimalista focada em UX para validação rápida de hipóteses.
